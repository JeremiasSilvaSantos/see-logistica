 SEE Logística

Projeto acadêmico de interface web para um sistema de logística e entregas.

 Sobre o projeto

O SEE Logística apresenta uma interface com diferentes perfis de acesso:
- Entregador
- Cliente
- Operador de Micro Hub

O protótipo reúne telas e fluxos relacionados a rotas, entregas, pedidos, documentos do entregador, pagamentos demonstrativos, notificações, ganhos e relatórios.

Tecnologias identificadas

- HTML5
- CSS3
- JavaScript
- Google Fonts (Plus Jakarta Sans)
- Integração de navegação com Google Maps por link

Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `see-app.html` em um navegador atualizado.
3. Para visualizar melhor a interface, utilize a visualização responsiva ou a janela do navegador em formato de celular.

Não é necessário instalar dependências para abrir o protótipo.

Observações importantes

Este material é um protótipo front-end acadêmico. A versão enviada concentra a interface em um arquivo HTML e utiliza dados e credenciais demonstrativas no próprio código. Não foi identificada integração com API ou armazenamento persistente no arquivo analisado.

Por isso, não utilize dados pessoais, documentos reais, senhas reais ou informações financeiras verdadeiras neste protótipo. As telas de pagamento e autenticação devem ser tratadas como demonstração, não como serviços reais.
